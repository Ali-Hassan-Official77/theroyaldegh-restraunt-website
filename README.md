# The Royal Degh

Premium Pakistani restaurant ordering site for **The Royal Degh**, styled around the supplied dark emerald / antique-gold restaurant reference.

## Stack
- Next.js 16.3.3
- React 19.2.0
- TypeScript 5.8
- lucide-react
- motion
- zod

## Included
- Responsive desktop + mobile UI
- Dark mode / light mode toggle
- Animated premium SVG logo + favicon
- Hero carousel with featured dishes
- Menu search + category filtering
- Product detail pages
- Favorites, cart and local order state
- Server-side order validation with Zod
- Cash-on-delivery checkout
- Order tracking / reorder flow
- Professional restaurant location and contact sections
- Skeleton loading screen
- Toast feedback for user actions
